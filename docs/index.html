PDF閲覧ツール。
見開きを、横にめくる。

受験参考書や過去問集の見開きPDFを、縦スクロールではなく横にスライドして 連続で読み流すためのビューアです。ブラウザだけで動きます。

ブラウザで開く ダウンロード（.zip） GitHubでソースを見る

v1.1.1 ・ PC・スマホのブラウザで動作 ・ MIT License ・ ZIP版は完全オフラインで使え、重いPDFの描画もワンテンポ滑らかです

はじめかた

4つの手順だけ。セットアップも会員登録もありません。

  1. ZIPをダウンロード

    上の「ダウンロード」ボタンから pdf-viewer-tool.zip（約1.5MB）を保存します。

  2. 展開する

    ダウンロードしたZIPを右クリック →「すべて展開」。好きな場所に置いて構いません。

  3. 起動.bat を開く

    ダブルクリックするだけ。Pythonが入っていない場合は、自動でブラウザに直接開く方式に切り替わります。

  4. PDFをドラッグ＆ドロップ

    あとは見開きを見ながら、矢印キーやホイールで横に読み進めるだけです。

スマホ・タブレットでも読めます

ダウンロードも展開も要りません。ブラウザで開いて、PDFを選ぶだけです。

  • ・ブラウザ版を開くだけで使えます。アプリのインストールは不要です。ホーム画面に追加しておけば、次からは1タップで開けます。
  • ・選んだPDFは端末から出ません。ブラウザ版でも処理はすべて端末の中で完結します。通信が発生するのはツール本体を読み込む最初の1回だけで、PDFを開いたあとは何も送受信しません。完全にオフラインで使いたい場合はZIP版をお使いください。
  • ・スワイプでページ送り、タップでバーの開閉。画面を軽くタップすると上下のバーが隠れ、全画面で読めます。
  • ・見開きの本は横向きがおすすめです。縦向きのままだと見開き2ページ分が画面幅に収まらないため、左右に振りながら読むことになります。

ブラウザ版とZIP版、どちらを使う？

PCでもスマホでも、まずはブラウザ版を開けば十分です。ZIP版は次のような場合に。

  • ・完全にオフラインで使いたい。ブラウザ版もPDFの処理自体はオフラインで動きますが、最初にツール本体を読み込む通信だけは発生します。ネット接続がまったく無い環境ではZIP版を。
  • ・数百ページの重いPDFをページ送りで滑らかに読みたい。同梱の起動.batから開くとPDFの描画が別スレッドになり、引っかかりが減ります（ブラウザ版・index.html直接起動はメインスレッド描画）。
  • ・友人に丸ごと渡したい。フォルダごとZIPにして送るだけで、相手はダウンロード＆展開して使えます。

できること

見開きの本を「めくる」ときの動きを、そのままブラウザの中に再現しています。

01

横スライド表示

見開きを横一列に並べ、1見開きずつのスナップ送り、または自由スクロールで連続して読めます。単ページ／見開きは縦横比から自動判定。

02

右綴じ・左綴じ切替

日本の参考書に合わせた右綴じにも対応。スクロールバーと送りボタンも綴じ方向に合わせて向きが反転します。

03

複数PDFをタブで管理

何冊でも同時に開いておけます。[]キーやクリックで切替、読書位置は本ごとに記憶されます。

04

目次パネル

PDFのしおりを自動表示。無ければ紙の目次ページを登録して、本文を読みながら参照できます。

05

開いていたタブを次回も

Chrome・Edgeでは、閉じる前に開いていたPDFが次に開いたときも自動で復元されます。ファイルの中身は保存せず、参照だけを覚えておく仕組みです。

ページ番号のズレも直せます

自炊PDFは表紙や白紙のぶんだけ、本に印刷された番号とPDFの枚数がズレます。 目次パネルで、実物と番号を対応づけておけます。

PDF 4枚目 ＝ 本の p.1
PDF 11枚目 ＝ 本の p.7

対応づけは複数登録でき、そこから先は一定間隔として計算します。 章の途中に白紙が挟まってズレ量が変わっても、変わった所で1つ足せば以降が正しくなります。

安全性について

友人・知人に配るためのツールなので、中身を隠す理由がありません。

  • ・外部への通信は一切ありません。アクセス解析や自動更新の類は無く、読書位置や目次の登録内容もあなたのブラウザの中だけに保存されます。
  • ・ネット接続がなくても動きます。PDF描画エンジン（PDF.js）を同梱しているため、オフラインでも使えます。
  • ・中身は全部読めます。実行ファイル（.exe）ではなく、すべて .html と .js のテキストです。GitHubでソースを公開しています。
  • ・初回起動時の警告について。Windowsが「発行元不明」と表示することがありますが、未署名の個人配布ツールでは一般的な表示です。心配な場合は起動前にソースをご確認ください。
