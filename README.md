# PDF閲覧ツール

見開きページを横一列に並べて、連続で読み流すためのPDFビューアです。
受験参考書・問題集などの自炊PDFを、紙の本をめくる感覚で流し見することを想定しています。

インストール不要。`index.html` をダブルクリックすればブラウザで動きます。

**[→ 使い方ガイド（スクリーンショット付き）](https://pdf-slide-viewer.github.io/pdf-viewer-tool/)**
**[→ ダウンロード（.zip / 約1.5MB）](https://github.com/pdf-slide-viewer/pdf-viewer-tool/releases/latest)**

## 使い方

| 開き方 | 手順 |
|---|---|
| かんたん | `index.html` をダブルクリック → PDFをドラッグ＆ドロップ |
| 推奨 | `起動.bat` をダブルクリック（ローカルサーバー経由で描画が別スレッドになり滑らか） |

複数のPDFを同時に選ぶ／ドロップすると、**それぞれ別のタブで開きます**。
ツールバーの「結合」をONにすると、選んだファイルをファイル名順に**1冊につなげて**1タブで開きます（上下巻など）。

## タブ

- タブバーの `＋` またはツールバーの「開く」でPDFを追加できます。何冊でも同時に開いておけます。
- タブをクリック、または `[` `]` キーで切り替え。`1`〜`9` で直接指定できます。
- タブの `×`、中クリック、`W` キーで閉じます。閉じたPDFのメモリは解放されます。
- 読んでいた位置はタブごとに保持され、切り替えて戻ると同じ見開きに戻ります。
- すでに開いているPDFを再度開こうとした場合は、新しいタブを作らずそのタブに切り替えます。

## 目次パネル

ツールバーの「📑 目次」または `T` で、PDFの左に並べて開きます（本文は覆いません）。
パネル右端のドラッグで幅を変えられます。中身は次の2つです。

### 1. PDFのしおり（あれば自動表示）

PDFに「しおり（アウトライン）」が埋め込まれていれば、クリックできる目次として自動で一覧表示します。
しおりはページ番号ではなく**ページの実体を指している**ので、表紙や白紙が何枚挟まっていても
**ズレは起きません**。ただし自炊スキャンのPDFには通常入っていないため、その場合は次を使います。

### 2. 紙の目次ページを登録する

本の**目次が載っているページ自体**を登録しておき、本文を読みながら参照します。

1. 目次のページを表示する
2. パネルの**「＋ 今の見開き」**（または `Shift+T`）で登録
3. 以降はいつでも `T` で開けば、本文を見ながら目次を確認できます

`−` `＋` で目次画像を拡大・縮小。各項目の「このページへ」でその目次ページへ移動、`×` で登録解除。

## ページ番号のズレ合わせ

自炊PDFは表紙・扉・白紙が挟まるため、**本に印刷されたページ番号とPDFの何枚目かは一致しません**。
パネルの2段目で、実物と番号を対応づけておけます。

```
[右ページ (PDF 6枚目) ▼]  ＝ 本の p.[ 3 ]  [合わせる]
```

- 選択肢には**いま表示している見開きのページ**が、右ページ／左ページ付きで並びます
  （綴じ方向に追従するので、画面のどちらを指しているか迷いません）。
- そのページに印刷されている番号を入れて「合わせる」を押すだけです。
- 対応づけは複数登録でき、**そこから先は一定間隔**として計算します。
  つまり**章の途中に白紙が入ってズレ量が変わっても、変わった所で1つ足せば以降が正しくなります**。
- 登録済みの対応は下にタグで並び、`×` で削除できます。
- 対応づけが1つも無い場合は、入力した番号を「PDFの通し番号」としてそのまま扱います。

あとは「本の p.〇〇 へ移動」に目次で見つけた番号を入れて Enter。
移動先は「本の p.7 → PDF 11枚目」のように表示されるので、合っているか確認できます。

登録した目次ページと対応づけは**タブ（PDF）ごと**に保存され、次に同じPDFを開いたときも復元されます。

## 操作

| キー・操作 | 動作 |
|---|---|
| `←` `→` | 前後の見開きへ（綴じ方向に追従。右綴じなら `←` が「次」） |
| `Space` / `↓` | 次へ（`Shift+Space` で前へ） |
| ホイール | 次へ／前へ。横スワイプはそのまま横スクロール |
| ドラッグ | 掴んでスライド |
| `Ctrl`+ホイール | ズーム |
| `Home` / `End` | 最初 / 最後へ |
| `[` `]` | 前 / 次のタブへ |
| `1`〜`9` | そのタブへ直接切替 |
| `W` | 今のタブを閉じる |
| `T` | 目次パネルを開く／閉じる |
| `Shift`+`T` | 今の見開きを目次ページとして登録 |
| `S` | スナップ切替（1見開きずつ ⇄ 自由スクロール） |
| `D` | 単ページ ⇄ 見開き 切替 |
| `R` | 綴じ方向の切替 |
| `F` | 全画面（マウスを上下端に寄せるとバーが一時表示） |
| `H` | バーの表示切替 |
| `O` | ファイルを開く |
| `0` `+` `-` | 等倍（高さフィット）／拡大／縮小 |

## 表示設定

- **自動判定** — ページの縦横比の中央値で、PDFが「すでに見開きでスキャン済み」か「単ページ」かを判定します。
  単ページなら自動で2ページを結合して見開きにします。
- **見開き（2ページ結合）／単ページ** — 自動判定が外れたときに手動で指定します（`D` キー）。
- **綴じ方向** — 右綴じは1ページ目が右端に来て、左へ進みます。左綴じはその逆（`R` キー）。
  下部のスライダーと送りボタンも綴じ方向に合わせて反転するので、
  右綴じでは「右端がはじめ、左へ進む」で見た目と操作が一致します。
- **表紙単独** — 1ページ目を表紙として単独表示し、以降を 2-3、4-5 … と組みます。
  これをオフにすると 1-2、3-4 … の組み方になります。ページのずれはここで直します。
- **結合** — 複数ファイルを1冊のタブにつなげて開きます（OFFならファイルごとにタブ）。
- 横長ページ（折り込み・見開き図など）は、見開きモードでも自動的に単独で配置します。

設定と「最後に見ていたページ」はブラウザに保存され、同じPDFを次に開くと続きから表示します。
※ 開いていたタブの一覧は復元されません（ブラウザの制約でファイルの実体を保存できないため）。

## URLで直接開く（`起動.bat` 経由のときのみ）

```
http://localhost:8777/index.html?src=参考書.pdf
http://localhost:8777/index.html?src=上巻.pdf&src=下巻.pdf          … 2タブで開く
http://localhost:8777/index.html?src=上巻.pdf&src=下巻.pdf&merge=1  … 1冊に結合して開く
```

PDFを `index.html` と同じフォルダに置けば、ブックマークから一発で開けます。

## 人に渡すとき

このフォルダごとZIPにして渡すだけです（約1.5MB）。インストールも設定も要りません。

- **Pythonが無くても動きます。** `起動.bat` はPythonを実際に起動して確認し、無ければ
  `index.html` を直接開く動作に切り替わります。
- PDF.js は `lib/` に同梱しているので、**ネット接続も不要**です。
- `?src=` によるURL直接指定だけは、`起動.bat` から起動したときにしか使えません
  （`index.html` を直接開いた場合、ブラウザがローカルファイルの読み込みを禁止するため）。
  通常の「開く」やドラッグ＆ドロップは直接開いた状態でも問題なく使えます。

動作確認は Chrome と Edge（Windows）で行っています。Firefox / Safari / Mac は未確認ですが、
特殊な機能は使っていないため動く見込みです。

## 構成

```
index.html      本体（HTML/CSS/JS すべて内蔵）
lib/            PDF.js 3.11.174（オフラインで動くよう同梱）
起動.bat        ローカルサーバーを立てて開く（Python があれば使用）
```

## 補足

- ページ画像は表示中の前後数ページぶんだけ描画し、離れたページは破棄します。数百ページのPDFでもメモリを圧迫しません。
- タブを切り替えると、表示していない本の描画済み画像は解放されます（PDF本体は開いたまま保持）。
- 巨大なスキャン画像は約1400万ピクセルを上限に縮小して描画します。
- `index.html` を直接開いた場合、ブラウザの制約でPDF描画がメインスレッドになります。動作はしますが、
  ページ送りの引っかかりが気になるときは `起動.bat` を使ってください。

## 安全性について

- 外部への通信は一切行いません（アクセス解析・広告・自動更新のたぐいもなし）。開いたPDFも、
  読書位置や目次の登録内容も、すべて**あなたのブラウザの中だけ**に保存されます。
- ネット接続がなくても動作します（PDF.js を `lib/` に同梱済み）。
- 中身はすべて `.html` と `.js` のテキストファイルです。実行ファイル（`.exe`）ではないので、
  エディタやブラウザの「ソースを表示」でそのまま読めます。
- `起動.bat` はローカルにPythonがあるか確認してサーバーを立てるだけの短いスクリプトです。中身は
  [起動.bat](起動.bat) からそのまま確認できます。
- 初回実行時にWindowsが「発行元不明」の警告を出すことがありますが、コード署名をしていない
  個人配布のツールでは一般的な表示です。心配な場合はダウンロード前にソースをひと通り読んでください。
